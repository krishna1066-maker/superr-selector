Methodology

From deliveries to decisions

01 / Define pressure

Last five scheduled overs, first ten overs after three wickets, opening powerplay after a wicket and super overs. These are pressure proxies.

02 / Compare in context

Reference groups use format, innings, phase and broad player role. A model-based adjustment reduces small-sample confidence.

03 / Test assumptions

The revised bowling list gives run prevention and wicket-taking equal weight. Changing the run share to 60% retains 9 of its top 10; to 40% retains all 10.

Model explained

How the ranking model works

This dashboard uses a transparent statistical ranking model. It has not trained a machine-learning algorithm to predict future match outcomes. All available 2022–2026 observations are assessed together; the scores describe this historical sample.

01 / Pressure performance · 40%

Batters: contextual runs minus 20 times dismissals. Bowlers: run prevention and wickets are scored separately with equal weight. Context uses format, innings, phase and broad role. Both use sample-size shrinkage.

02 / Consistency · 35%

Qualifying matches require at least six measured balls. Batters use a combined runs-wickets benchmark; bowlers are assessed separately for runs below expected and wickets above expected. Beta-based estimates temper small-match samples.

03 / Baseline change · 25%

Pressure performance is compared with the player's non-pressure level, adjusted using broad role and phase references. These groups are imperfect and may not match every player's situation.

Reading the score: Each component is ranked relative to the included player pool and combined using 40 / 35 / 25 weights. The result is a relative index, not a percentage chance of success. The batter model uses a 20-run wicket value. Both models use a 120-ball shrinkage constant as an assumption; the bowler model ranks run prevention and wicket-taking separately. No training/test split or out-of-sample validation was performed.

Data quality: 287 events with ambiguous extras were omitted from scoring. Bowlers’ runs are a minimum-penalty proxy, not official economy. No time-based split or future-performance validation was performed. No players were excluded by nationality, injury, availability or sample size.
